# Relatórios de agentes

Os relatórios de execução são associados a uma task em .ai/docs/tasks/.
Mantenha nesta pasta somente modelos ou documentação compartilhada; não use
relatórios soltos sem identificador de task.

## Convenção sugerida

Para uma task YYYY-MM-DD-descricao-curta, use:

    .ai/docs/tasks/YYYY-MM-DD-descricao-curta/
      task.md
      dev-report.md
      qa-report.md

O dev-report.md deve seguir o formato DEV_REPORT e o qa-report.md o formato
QA_REPORT definidos nos papéis e no workflow.
