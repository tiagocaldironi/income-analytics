# MF-FII v3

Versão congelada: `MF_FII_V3`. O ranking será segmentado economicamente e somará rank de atratividade (`yield recorrente / P/VP`) e rank de qualidade sustentável. Qualidade reúne operação, cobertura, alavancagem e concentração como pilar único. Dados inexistentes mantêm a ferramenta em `DATA_GAP`; nenhum ranking é fabricado.
