# Income Analytics

## Visão

O Income Analytics é uma plataforma para consolidação de patrimônio, investimentos e renda passiva.

O sistema deve permitir ao investidor responder perguntas como:

- Quanto ganhei no mês?
- Quanto recebi de dividendos?
- Quanto recebi de renda fixa?
- Quanto foi minha rentabilidade?
- Quanto da minha rentabilidade veio da valorização cambial?
- Quanto falta para atingir meus objetivos financeiros?
- Qual era meu patrimônio em qualquer data?

O sistema será orientado a eventos financeiros (Transactions), permitindo reconstruir qualquer estado histórico da carteira.
