# Threat model operacional

Escopo: código versionado, dependências e runners descartáveis. STRIDE orienta a matriz abaixo; não é pentest nem certificação de provedores/host. Fronteiras: navegador → FastAPI → sessão Firebase + vínculo local → contexto de usuário/carteira → repositórios SQLite; provedores públicos → parsing; GitHub PR → CI somente leitura → artefato com digest → controlador de entrega → staging descartável. Produção não participa dos testes.

| Ameaça / STRIDE | Controle e evidência | Lacuna / residual | Teste |
|---|---|---|---|
| Anônimo, token forjado/expirado/outro projeto / S | Admin SDK verifica assinatura, issuer/audience/expiry; revogação exigida; erros falham fechados; cookie HttpOnly + nonce local | SDK doubles não certificam Firebase real; emulator/cloud separados | test_identity_verification_policy; test_firebase_authorization anonymous/expired/replay |
| A acessa carteira/evento de B / E,I,T | authorize_request default-deny, get_owned, contexto por requisição, repositórios por carteira | Novos handlers de referência exigem revisão explícita; caches de mercado compartilhados só para dados públicos | every_registered_private_wallet_route; foreign_event_id; two_users_four_wallets |
| Modo local exposto / S,E | Limite de peer loopback + Host permitido + recusa de Origin externo em escritas; aliases produtivos exigem Firebase | Proxy/Windows/Tailscale reais NOT_VERIFIED; proprietário precisa aplicar procedimento futuro | baseline_hardening remote/forwarded/DNS rebinding/cross-site |
| CSRF/session replay / S,T | SameSite strict, Secure em HTTPS, CSRF cookie/header/origin/vínculo hash; logout invalida sessão local | XSS pode operar como usuário; CSP e escaping continuam necessários | csrf_host_body_size; logout replay |
| Payload/ZIP/XML abusivo / D,T | limite de stream, validação XLSX contra arquivos grandes, entidades e archive bombs; Pydantic; paths estáticos | Parsers offline e fornecedor comprometido não certificados; dívida média explícita no SAST | upload_archive_bombs_and_xml_entities; payload/CSRF matrix |
| SQL injection / T,I | SQLAlchemy/bind parameters; três interpolações SQL revisadas usam identificadores fixos ou quoting sqlite_master | Revisão sem prova formal de todos os caminhos | foreign selection IDs; malformed IDs; SAST B608 individual |
| Path traversal/banco externo / I,T | StaticFiles; validação de raiz explícita e resolução antes de abrir SQLite; staging Workspace.safe | ACLs, criptografia em disco e TOCTOU do host NOT_VERIFIED | database_boundary; delivery traversal/symlink/backup tests |
| XSS / E,I | escaping contextual existente; SAST JS para eval/Function/document.write/fontes DOM diretas; teste frontend saas_xss_characterization | Análise de padrões não é análise completa de fluxo; templates innerHTML requerem revisão; CSS inline transitório | frontend suite + JS pattern fixtures |
| SSRF/provedor comprometido / I,E | URLs de serviço fixas e símbolos/datas codificados; nenhuma URL arbitrária encontrada no contrato público | Redirect/DNS de fornecedores é risco médio; não afirmar egress deny no runtime real | B310 por local; PR7 egress guard somente staging |
| Segredo em código/history/artefato / I | scanner sem valores, revisão por bytes exatos para fixtures, scan de wheels; histórico acessível completo | Não inspeciona refs inacessíveis, dangling objects/LFS; não testa validade de credenciais | test_secret_detection; benign_marker_approval; artifact scan |
| Dependência comprometida / T,E | versões/hashes, OSV incluindo transitivas, SBOM ligado ao SHA/digest, Actions por SHA | CVE desconhecida não aparece no feed; disponibilidade do OSV falha fechada; CDN Firebase permanece confiança externa | vulnerable_dependency_fixture; unavailable/partial/pagination |
| PR/workflow/artefato trocado / T,E | tokens read-only; sem pull_request_target; Engineering obrigatório inclui Security; PR7 verifica workflow/run/job/SHA/digest/ancestor | GitHub runner e conta mantenedora fora da certificação | ci/test_delivery source/digest/production negatives; workflow policy tests |
| Vazamento em logs / I,R | redaction de bearer, query credentials, userinfo e e-mail antes dos handlers; exceção sem payload bruto em relatórios | Dados arbitrários adicionados via extra, logs externos/anteriores e valores financeiros exigem política própria | log_credentials_email_and_exception; safe_junit |
| Banco corrompido/rollback inseguro / D,T | PR7 backup consistente SQLite, integridade, schema e estado semântico; schema incompatível bloqueado, sem downgrade | Exclusivamente sintético; backup produtivo NOT_VERIFIED | ci/test_delivery + CD staging |
