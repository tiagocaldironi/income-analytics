# ADR-001 — Objetivo do Projeto

## Status

Aceito

## Contexto

Desejamos construir uma plataforma para acompanhar patrimônio, renda passiva e evolução financeira utilizando práticas modernas de engenharia de software.

O projeto também será utilizado como ferramenta de aprendizado para desenvolvimento de software.

## Decisão

O projeto será desenvolvido incrementalmente, priorizando qualidade, testes automatizados, documentação e arquitetura limpa.

## Consequências

A evolução será mais lenta no início, porém com menor retrabalho e maior facilidade de manutenção.
