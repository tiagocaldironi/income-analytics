Título

Toda comunicação externa ocorrerá exclusivamente através da API.

Contexto

O sistema poderá possuir diversos consumidores (Web, IA, Mobile, Dashboard).

Decisão

Nenhum cliente acessará diretamente o banco de dados.

Toda interação será realizada através da API.

Consequências

Regras centralizadas.
Segurança.
Facilidade para evoluir.
Facilidade para testar.
Possibilidade de múltiplos clientes.
